Bounded kernel

Lumen

A control loop that keeps a mission, scores beliefs, attacks its own plans, and only then writes a file. A tick log is not a result. A committed file is.

Perceive. Propose three different plans. Attack them. Simulate the survivor. Commit, abort, or withhold.

What is in the repo

  • lumen.py — the kernel
  • sandbox — local server on port 3000, text readings, response files
  • altnet.py — a small alternative internet: content hash names, neighbor get, no DNS
  • plan_gate.py — the coding agent’s plan gate
